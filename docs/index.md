# Submit Express

Suivi personnel de candidatures **undergraduate** pour la rentrée **2027** : universités,
bourses et dispositifs de financement. Chaque page décrit la procédure, les critères,
les documents requis et le calendrier, sous forme de checklist interactive.

Cochez les cases au fil de l'eau : votre progression est **enregistrée localement**
(par défaut, dans les `données persistantes de navigation de ce poste`) et un tableau
de bord récapitule l'avancée globale.

## Comment ça marche

- Les **cases à cocher** sur chaque page se bul-guent en temps réel.
- Un **barre de progression** apparaît sous le titre de chaque application.
- Le **statut** d'une application peut être marqué manuellement
  (à faire / en cours / prêt / déposé).
- Le **tableau de bord** agrège l'ensemble des applications et des bourses.

!!! tip "Conseil"
    Commencez par les pages « Financement & mécanismes d'aide » : les demandes
    d'autorisation (fee waivers, CSS Profile) ont des échéances précoces à ne pas rater.
