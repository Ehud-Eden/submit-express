## 1.4 Exigence d'anglais

- **REQUIS** pour tout candidat international non-anglophone n'ayant pas passé les **deux dernières années** dans un établissement dont l'enseignement principal est en anglais. Un candidat burkinabè (lycée francophone) est en pratique **concerné**.
- Tests acceptés : TOEFL iBT (min. recommandé 100, échelle pré-21 janv. 2026 — [À CONFIRMER] nouvelle échelle), IELTS Academic 7.5, Duolingo English Test 130 (pas de coupons fournis par Amherst).
- Waiver : uniquement les conditions ci-dessus (2 ans en anglais) ou langue maternelle anglaise — « no exceptions ». Détermination via le supplement (Common App/Scoir) ou le formulaire du portail candidat.
- Scores self-reportés acceptés ; officiels exigés seulement en cas d'admission + inscription.

## 1.5 Coûts

75 $ non remboursables. Fee waiver : case dédiée Common App / Coalition / [Quick Pass](https://admission.amherst.edu/register/quickpass). Payable à la soumission.

- CSS Profile — **code Amherst 3003** — à compléter dans la devise du pays d'origine. Disponible le 1er octobre 2026 pour 2027-28.

- Justificatifs de revenus 2025 : à téléverser au Financial Aid Portal (PDF uniquement, traduction anglaise maison acceptable, signatures originales — pas de signatures numériques).

- Business/Farm Supplement si un parent possède une entreprise/ferme.

## Étapes — synthèse opérationnelle

### Étape 1 — Plateforme

Common App, Coalition/Scoir ou QuestBridge (faible revenu → QuestBridge National College Match est pertinent). Ajouter Amherst.

### Étape 2 — Anglais

sans exemption possible pour un lycée francophone, prévoir TOEFL/IELTS/DET à l'automne 2026 ; codes : TOEFL 3003 ; DET/IELTS : « Amherst College ».

### Étape 3 — École

le lycée transmet School Report, transcript (avec diplôme requis avant inscription), recommandation du conseiller + 2 enseignants, premier trimestre (ED), mid-year (RD). Documents officiels jamais envoyés par le candidat.

### Étape 4 — Essais

essai principal + [Writing Supplement](https://www.amherst.edu/admission/apply/firstyear/writingsupplement) (y compris questions d'exemption d'anglais).

### Étape 5 — Scores facultatifs

SAT/ACT OPTIONNEL (self-report OK, superscore) ; InitialView OPTIONNEL (déjà réalisé uniquement).

### Étape 6 — Frais

waiver via la plateforme ou Quick Pass ; sinon 75 $ à la soumission.

### Étape 7 — Soumission

vérifier toutes les sections ; ED = engagement contraignant ; conserver la confirmation.

### Étape 8 — Aide financière

CSS Profile (code 3003, devise locale) ; ISFAA si CSS impossible ; attendre l'e-mail d'accès au Financial Aid Portal puis téléverser revenus 2025 (PDF, traduction maison OK). Deadlines : 13 nov. / 15 janv.

### Étape 9 — Suivi

[page Current Applicants](https://www.amherst.edu/mm/45466) + portail ; jusqu'à 1 semaine de traitement des documents — ne pas doublonner les envois.
