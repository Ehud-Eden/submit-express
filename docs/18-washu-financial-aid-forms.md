# PARTIE I — Réponse à la question : quel formulaire pour qui ?

## 1.1 Synthèse officielle

| Situation | Formulaire requis | Source officielle |
|---|---|---|
| **International, première année (votre cas), demande d'aide** | **CSS Profile — REQUIS** (« The CSS Profile should be submitted by all need-based financial aid applicants. This includes incoming first-year international applicants ») | [International Applicant Process](https://financialaid.washu.edu/apply-for-aid/international-applicant-process/) |
| **International qui ne peut pas payer le CSS Profile (25 $)** | **Formulaire institutionnel WashU en alternative** (« If an international applicant is unable to pay the fee to submit the CSS Profile, they may apply for financial aid from WashU using our institutional form ») — disponible dans **WashU Pathway à partir d'octobre, après soumission de la candidature d'admission** | idem |
| International transfert | **AUCUN** — « International applicants for transfer admission are not eligible to apply for financial aid from WashU » | idem |
| US citizens/permanent residents | CSS Profile (+ FAFSA + Noncustodial Profile si applicable) | [First-Year US Applicants](https://financialaid.washu.edu/apply-for-aid/first-year-us-applicants/) |

**Réponse directe** : pour vous (international, first-year), le **CSS Profile est le formulaire demandé** ; le formulaire institutionnel WashU n'existe que comme **alternative gratuite** si le paiement du CSS Profile est impossible. L'un remplace l'autre — les deux ne sont **pas** nécessaires. **Un seul suffit.**

## 1.3 Décision — CSS Profile ou formulaire institutionnel

**Option A — CSS Profile** (voie standard) :
- Coût : 25 $ initial + 16 $/université supplémentaire (College Board).
- Code école WashU : **6929**.
- À compléter dans la devise de votre pays.
- Waiver College Board du CSS : principalement US — [CONDITIONNEL].

**Option B — formulaire institutionnel WashU** (alternative gratuite) :
- Gratuit, spécifique WashU.
- **Disponible uniquement après** la soumission de la candidature d'admission (octobre) dans **WashU Pathway**.
- Ne pas attendre le dernier jour : la deadline financière du plan choisi s'applique aussi à cette option.

**Point de vigilance** : quelle que soit l'option, la deadline financière du plan d'admission (EA/ED I : 2 nov. ; ED II/RD : 4 janv. — voir [11-washu.md](11-washu.md)) est la même. Sans dépôt à temps → plus jamais d'aide WashU.

## 1.6 Suivi — Financial Aid Portal

- Le **Financial Aid Portal** (dans WashU Pathway) est **séparé** du dossier d'admission : checklist financière personnalisée, offre d'aide, gestion.
- Un compte Pathway est créé automatiquement après (1) soumission de la candidature d'admission (avec coche « aide financière ») **et** (2) soumission du CSS Profile ; accès sous quelques jours.
- Réévaluation possible en cas de circonstances exceptionnelles (« special circumstances »).

## Étapes — synthèse opérationnelle

### Étape 1 — Coche d'aide financière

sur Common App ou Coalition App, indiquer la demande d'aide need-based dès le remplissage (la soumission seule suffit pour créer le compte — l'application complète peut suivre).

### Étape 2 — Soumission de l'admission

déclenche l'accès à Pathway (octobre).

### Étape 3 — Option A (CSS Profile)

[cssprofile.collegeboard.org](https://cssprofile.collegeboard.org) — code 6929, devise locale, deux parents si séparés ; avant le 2 nov. / 4 janv.

### Étape 4 — Option B (formulaire institutionnel)

dans Pathway à partir d'octobre, après la soumission d'admission — gratuite, même deadline.

### Étape 5 — Parent non gardien

WashU exige le CSS Profile des deux foyers biologiques ; si contact impossible, formulaire de renonciation (waiver request) via Pathway.

### Étape 6 — Financial Aid Portal

vérifier la checklist personnalisée ; c'est le seul lieu où voir l'offre.

### Étape 7 — Documents supplémentaires

répondre vite ; tout formulaire est dans la « form library » de Pathway.

### Étape 8 — Offre d'aide

publiée avec la décision d'admission (100 % du besoin démontré, sans prêts) ; après admission : AOFS + relevés bancaires pour l'I-20.
