## 1.5 Aide financière

- CSS Profile **requis** pour tous les demandeurs d'aide, y compris internationaux first-year — code **6929**.
- Deadline financière = deadline du plan d'admission choisi ([voir calendrier](#16-calendrier)).
- **Sans dépôt à la deadline → plus jamais d'aide** pendant le cursus.
- Formulaire institutionnel WashU : uniquement comme **alternative pour ceux qui ne peuvent pas payer le CSS Profile** — disponible dans **WashU Pathway** à partir d'octobre, après soumission de la candidature d'admission. Détails : [18-washu-financial-aid-forms.md](18-washu-financial-aid-forms.md).
- Noncustodial Parent Profile requis si parents séparés (formulaire de renonciation possible).

## Étapes — synthèse opérationnelle

### Étape 1 — Plateforme

Common App ou Coalition App ; cocher l'intention de demander l'aide financière (création du dossier financier dans Pathway).

### Étape 2 — Anglais

TOEFL/IELTS/DET obligatoires — réserver tôt (centres limités au Burkina).

### Étape 3 — École

transcripts originaux certifiés + description du système de notation + BAC + certificat de fin d'études + **traductions certifiées** ; School Report + Teacher Evaluation + Counselor Recommendation via la plateforme.

### Étape 4 — Essais

supplément WashU officiel.

### Étape 5 — Plan

EA non contraignant ; ED I/II contraignants ; RD = comparaison des offres. Le choix fixe la deadline financière — décisif pour l'aide.

### Étape 6 — CSS Profile ou formulaire institutionnel

CSS Profile (code 6929) en priorité ; si paiement impossible, le formulaire institutionnel est disponible dans WashU Pathway après soumission de la candidature (à partir d'octobre). Voir [18-washu-financial-aid-forms.md](18-washu-financial-aid-forms.md).

### Étape 7 — Frais

75 $ effacés pour les demandeurs d'aide et cas de hardship.

### Étape 8 — Soumission

vérifier toutes les sections ; conserver la confirmation ; l'accès au Financial Aid Portal/Pathway se fait sous quelques jours après CSS + application.

### Étape 9 — Suivi

Pathway (checklist financière personnalisée, formulaire de renonciation parent non gardien si besoin) ; après admission : AOFS + relevés bancaires → I-20 → visa F-1.
