# Chinese Government Scholarship (CSC) — Guide de candidature bachelor (rentrée 2027)

**Profil concerné** : candidat du Burkina Faso visant un bachelor en Chine, rentrée 2027.
**Nature** : bourse du gouvernement chinois administrée par le **China Scholarship Council (CSC)** — candidature **séparée** de toute admission (on candidate à la bourse via une agence ou une université chinoise). Ce n'est ni Common App ni une candidature américaine.
**Date de vérification** : 2026-09-20.

⚠️ **Avertissement sources** : le portail officiel est [campuschina.org](https://www.campuschina.org) (site officiel CSC). La description ci-dessous s'appuie sur des sources spécialisées recoupées (site chinesescholarshipcouncil.com — source **secondaire**) + extraits de pages officielles universitaires. Chaque information non confirmée par une source officielle directe est marquée [À CONFIRMER] ou « source secondaire ».

# PARTIE I — Comprendre le programme et vérifier mon éligibilité

## 1.1 Identité du programme

| Élément | Information |
|---|---|
| Programme | Chinese Government Scholarship (CGS) — administré par le China Scholarship Council (CSC) |
| Niveaux | Bachelor (licence), master, doctorat |
| Types de voie | **Type A** : via une agence de recrutement dans votre pays = **l'ambassade de Chine au Burkina Faso** (Chinese Embassy) · **Type B** : directement auprès d'une **université chinoise** · Type C : autres sources |
| Plateforme | Système de candidature en ligne CSC : **studyinchina.csc.edu.cn** (portal officiel) |
| Couverture | Bourse « fully funded » (frais de scolarité + allocation mensuelle + hébergement + assurance — montants exacts : [À CONFIRMER] sur campuschina.org) |
| Frais de candidature | GRATUIT (aucun frais CSC — tout intermédiaire payant est une arnaque [CONDITIONNEL]) |
| Limite officielle | **Maximum 3 candidatures par an : 2 de Type A + 1 de Type B** ; Type B = une seule université |

## 1.3 Voies de candidature — Type A vs Type B

| | Type A (ambassade) | Type B (université) |
|---|---|---|
| Qui traite le dossier | Agence de recrutement = ambassade de Chine au Burkina Faso | L'université chinoise choisie |
| Nombre autorisé | 2 max (agences différentes) | 1 seul |
| Avantage pour un bachelor burkinabè | Voie historique pour les lycéens ; placement par le gouvernement | Nécessite de viser une université précise ; les bourses bachelor de Type B sont moins courantes |
| Recommandation | [CONDITIONNEL] — contacter l'ambassade de Chine à Ouagadougou dès l'automne 2026 pour connaître la procédure locale et les documents exigés | |

6. [ ] Remplir et soumettre avant la deadline de l'agence/université ([Étape 6](#etape-6-soumission))
7. [ ] Suivre et préparer l'éventuel entretien ([Étape 7](#etape-7-suivi))
8. [ ] Après pré-admission : JW201/visa X1, arrivée ([Étape 8](#etape-8-apres-pre-admission))

## Étapes — synthèse opérationnelle

### Étape 1 — Ambassade

la voie Type A passe par l'ambassade/section éducation de la Chine au Burkina ; demander le calendrier local 2027 et les exigences documentaires.

### Étape 2 — Choix de la voie

max 3 dossiers (2 Type A + 1 Type B, une seule université en Type B).

### Étape 3 — Documents

faire notariser les relevés/diplômes ; traduction (anglais/chinois) selon exigences [À CONFIRMER].

### Étape 4 — Visite médicale

formulaire officiel « Physical Examination Record for Foreigner » à remplir par un hôpital agréé.

### Étape 5 — Portail CSC

[studyinchina.csc.edu.cn](http://studyinchina.csc.edu.cn/) — créer le compte, choisir le type (A/B) et les codes d'agence/université fournis par l'ambassade ou l'université.

### Étape 6 — Soumission

vérifier chaque section ; aucune modification après soumission [À CONFIRMER] ; conserver la confirmation.

### Étape 7 — Suivi

l'agence/université évalue, le CSC tranche ; entretien possible [À CONFIRMER].

### Étape 8 — Après pré-admission

recevoir les documents officiels (JW201/JW202 + lettre d'admission) → visa X1 à l'ambassade de Chine → arrivée fin août/septembre ; année préparatoire de chinois probable avant le bachelor.
