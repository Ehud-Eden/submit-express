## Étapes — synthèse opérationnelle

### Étape 1 — Plateforme

les trois plateformes sont historiquement acceptées (traitées équitablement) ; QuestBridge pertinent pour profils à faible revenu.

### Étape 2 — Tests et anglais

SAT/ACT optionnels — ne les soumettre que si avantageux. Anglais : soumettre un score officiel ou self-reporté si le dossier ne démontre pas déjà la maîtrise.

### Étape 3 — École

le conseiller envoie transcript + formulaires ; inviter les recommandants dans la plateforme.

### Étape 4 — Essais

supplément UChicago exige créativité ; prompts officiels de l'année.

### Étape 5 — Aide financière

compléter l'International Financial Aid Worksheet via le portail candidat ; préparer les justificatifs de revenus ; vérifier les instructions sur la page aide financière internationale.

### Étape 6 — Frais

fee waiver via la plateforme si éligible.

### Étape 7 — Soumission

vérifier toutes les sections ; conserver la confirmation.

### Étape 8 — Suivi

portail UChicago ; répondre aux demandes de documents ; après admission : I-20 + preuve de financement (règle fédérale) → visa F-1.
