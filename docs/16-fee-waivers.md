## 1.2 Common App fee waiver

- « International students **may be eligible** for a need-based Common App fee waiver. You can find the Common App fee waiver in the **Profile section** » (guide officiel international Common App). VÉRIFIÉ — SOURCE OFFICIELLE ([PDF officiel](https://www.commonapp.org/static/84292aaf2c3c2ddb4425749e97dc9b00/Resource_FY_International_ENG_2025.06.24_1.pdf)).
- **Mais chaque université décide** d'accepter ou non ce waiver : « Each college has their own policies » — acceptation non garantie ([Student Solutions Center](https://appsupport.commonapp.org/applicantsupport/s/article/What-do-I-need-to-know-about-the-Common-App-fee-waiver)).
- Pratique fréquente : le waiver demandé dans Common App déclenche un e-mail d'endossement au conseiller de l'école (exemple officiel Duke). [CONDITIONNEL — mécanisme propre à chaque université]
- Alternatives : « 500+ colleges have no application fee for international students » (Common App).

## 1.5 CSS Profile — fee waivers

- Le CSS Profile coûte 25 $ (+16 $/université supplémentaire). Des waivers College Board existent mais ne concernent en principe pas les internationaux non-US [CONDITIONNEL].
- **NYUAD** propose ses propres « fee payment codes » pour le CSS Profile (demande après activation du portail NYU, à partir du 1er octobre, quantité limitée) : voir [17-nyuad-fee-waiver.md](17-nyuad-fee-waiver.md).
- **Bowdoin** : les internationaux ne soumettent le CSS Profile qu'après admission ; en cas d'impossibilité de payer, contacter sao@bowdoin.edu.
- **WashU** : formulaire institutionnel gratuit en alternative si le CSS Profile est inabordable : voir [18-washu-financial-aid-forms.md](18-washu-financial-aid-forms.md).
- **Amherst** : ISFAA accepté en alternative (upload au Financial Aid Portal).

# PARTIE II — Procédure générale d'utilisation des waivers

## 2.1 Checklist chronologique

1. [ ] Lister vos candidatures payantes et le mécanisme de chacune ([tableau 1.4](#14-tableau-de-correspondance-quelle-dispense-pour-quelle-candidature))
2. [ ] Pour chaque université Common App : activer le fee waiver dans la section Profile
3. [ ] Notifier le conseiller scolaire pour les endossements requis (Duke, etc.)
4. [ ] Pour Soka : faire parvenir le waiver papier/College Board avant la soumission
5. [ ] Pour NYUAD : répondre « yes » à la question waiver dans Common App (irréversible après soumission)
6. [ ] Vérifier sur chaque portail que le statut des frais est bien « waived »
7. [ ] Conserver les confirmations

## 2.2 Points d'attention

- Le waiver Common App n'est **pas** universel : vérifier la politique de chaque université (page fee waiver officielle).
- NYUAD : « We cannot consider your fee waiver request after you apply for admission if you did not respond with 'yes' on the Common Application » — irréversible.
- Soka : un waiver non reçu = dossier incomplet.
- U of T/UBC : aucune dispense identifiée — budgétiser les frais OU passer par EducationUSA Opportunity Funds ([15-educationusa-opportunity-funds.md](15-educationusa-opportunity-funds.md)) si retenu.
