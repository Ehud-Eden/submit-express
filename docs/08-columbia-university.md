# Columbia University — Guide de candidature first-year (rentrée 2027)

**Profil concerné** : candidat international du Burkina Faso, entrée Fall 2027 = cycle 2026-27.
**Points critiques officiels** : internationaux évalués en **need-aware** (le besoin financier compte à l'admission) ; demande d'aide à indiquer **dès la candidature** (impossible d'y prétendre plus tard) ; SAT/ACT **optionnel pour Fall 2027, obligatoire dès le cycle 2027-28**.
**Date de vérification** : 2026-09-20.

## 1.5 Essais

Essai principal de la plateforme + réponses Columbia (« Columbia-specific questions ») : motivation académique, listes d'ouvrages/activités, « why Columbia ». Authenticité exigée (Accuracy & Authenticity, Honor Pledge, politique IA).

## 1.6 Aide financière

- **Règle absolue** : « International applicants must indicate their plan to apply for financial aid when submitting their admission application. If admitted without requesting financial aid, international students may not change their status to apply for aid, even if their financial circumstances change. »
- Formulaires internationaux : **CSS Profile** + **documents de revenus parentaux via IDOC** (Institutional Documentation Service).
- Average international award : 79 375 $/an ; pas de prêts ; 100 % du besoin.
- Deadlines ED/RD : [À CONFIRMER] — consultez la page officielle au moment du cycle (la page 26-27 CSS Profile existe sur le site du financial aid).
- CSS Profile fee : 25 $ (première) + 16 $/université ; waivers College Board possibles [CONDITIONNEL].

## 1.7 Coûts

85 $ non remboursables, payables en ligne ; « If paying the application fee is a significant financial burden for your family, we encourage you to request an automatic fee waiver through your admission application. » Formulaire d'éligibilité au waiver disponible en amont.

## Étapes — synthèse opérationnelle

### Étape 1 — Plateforme

Common App ou Coalition App ; Columbia College ou Engineering (l'ingénierie exige une reco maths/sciences).

### Étape 2 — Cocher l'aide financière

l'étape la plus importante pour un candidat burkinabè — sans cette coche, jamais d'aide Columbia.

### Étape 3 — École

Secondary School Report avec transcript officiel + profil d'école ; 2 recommandations d'enseignants ; midyear report.

### Étape 4 — Essais

questions Columbia (listes, essais courts) ; travail original exigé.

### Étape 5 — Tests

optionnels pour Fall 2027 — si vous les passez, envoyer avant la deadline ; sinon prévoir l'obligation pour un éventuel cycle suivant.

### Étape 6 — CSS Profile + IDOC

code Columbia 2095 (CSS Profile — code vu sur la page du financial aid ; [À CONFIRMER]) ; documents de revenus via IDOC ; suivre les instructions du portail Columbia.

### Étape 7 — Frais

waiver automatique demandé dans l'application.

### Étape 8 — Soumission

vérifier chaque section ; conserver la confirmation.

### Étape 9 — Suivi

portail candidat ; décision ; après admission, dossier de visa (I-20) via ISSO.
