# Yale University — Guide de candidature first-year (rentrée 2027)

**Profil concerné** : candidat international du Burkina Faso, entrée Fall 2027 = cycle 2026-27.
**Points critiques officiels** : admission **need-blind pour tous** ; SAT **ou** ACT **requis** (pas d'option) ; aide financière need-based uniquement, incluant billets d'avion 2×/an ; l'ISFAA n'est **pas** accepté — Yale envoie ses propres formulaires.
**Date de vérification** : 2026-09-20.

- **L'ISFAA n'est PAS accepté** : Yale contacte directement le candidat avec ses formulaires propres.
- Checklist personnalisée sur le **Yale Admissions Status Portal** ; documents soumis via **IDOC** (College Board).
- Année 2027-28 : documentation de revenus **2025**.
- Deadlines prioritaires 2027-28 (officielles) : **QuestBridge 1er nov. 2026 · Early Action internationaux 1er déc. 2026 · Regular Decision 15 févr. 2027**.
- Parents séparés : informations des deux parents (waiver possible pour le parent non gardien).
- Un dossier incomplet à la deadline n'annule pas l'éligibilité — l'offre sera faite avant la date de réponse. VÉRIFIÉ — SOURCE OFFICIELLE.

## Étapes — synthèse opérationnelle

### Étape 1 — SAT/ACT

REQUIS — centres limités au Burkina ; s'inscrire dès l'ouverture des sessions 2026.

### Étape 2 — Anglais

TOEFL/IELTS/DET/Cambridge pour francophones ; InitialView accepté aussi comme preuve.

### Étape 3 — Plateforme

QuestBridge très pertinent (Match = admission + bourse maximale) ; sinon Common App/Coalition.

### Étape 4 — École

tous les documents français → traduction certifiée par un tiers (jamais auto-traduite).

### Étape 5 — Essais

prompts officiels de l'année.

### Étape 6 — Aide financière

cocher l'intérêt — Yale envoie ensuite ses formulaires propres (pas d'ISFAA).

### Étape 7 — Frais

fee waiver Yale [À CONFIRMER] procédure.

### Étape 8 — Soumission

avant le 1er nov. (SEA non-contraignant) ou 2 janv. (RD) ; conserver la confirmation.

### Étape 9 — Formulaires financiers

surveiller le Status Portal + e-mails de Yale ; soumettre via IDOC les formulaires Yale + revenus 2025 avant les deadlines prioritaires.

### Étape 10 — Suivi

le portail liste tous les documents manquants ; après admission : I-20, visa F-1 ; pas de re-candidature d'aide chaque année.
