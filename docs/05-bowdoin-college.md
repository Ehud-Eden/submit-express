## International Students at Bowdoin

- « Bowdoin College is need blind for international students » — la capacité à payer n'est **pas** un facteur d'admission.
- Bowdoin couvre le besoin calculé de tous les admis, sans prêts ; moyenne des bourses ~72 883 $/an.
- **Internationaux (hors Canada)** : les documents d'aide financière ne sont exigés qu'**après** l'offre d'admission — puis sous **7 jours**.
- Bowdoin n'accepte plus l'ISFAA ni le IACAC Form : le **CSS Profile** est requis (contacter sao@bowdoin.edu après admission si le paiement du CSS Profile est un obstacle).
- Examens nationaux (WASSCE, etc.) : résultats officiels exigés. Le transcript doit être traduit en anglais (traduction par l'école ou un agent officiel de préférence).

# PARTIE II — Procédure complète de candidature

## 2.1 Checklist chronologique

1. [ ] Ouvrir Common App/Coalition dès le 1er août ([Étape 1](#etape-1-creer-le-dossier))
2. [ ] Demander les 3 recommandations ([Étape 2](#etape-2-recommandations))
3. [ ] Préparer transcript + BAC + traduction ([Étape 3](#etape-3-documents-scolaires))
4. [ ] (Facultatif) réserver InitialView/Vericant/DET tôt ([Étape 4](#etape-4-entretien-independant-facultatif))
5. [ ] Rédiger les essais ([Étape 5](#etape-5-essais))
6. [ ] Soumettre avant ED1 15 nov. / ED2-RD 5 janv. (frais auto-effacés) ([Étape 6](#etape-6-soumission))
7. [ ] Après admission : CSS Profile + justificatifs sous 7 jours ([Étape 7](#etape-7-apres-admission-aide-financiere))

## Étape 1 — Créer le dossier

**Plateforme** : [Common App](https://www.commonapp.org) ou [Coalition on Scoir](https://www.scoir.com). **Vérification** : Bowdoin apparaît dans « My Colleges ». Aucun frais à anticiper si demande d'aide ou première génération (effacement automatique).

## Étape 2 — Recommandations

**Action** : inviter via la plateforme (1) le conseiller/proviseur, (2) un enseignant de 1re/terminale en matière principale, (3) une « other » recommandation. **Vérification** : statut « submitted » pour les trois.

## Étape 3 — Documents scolaires

**Action** : l'école envoie le transcript officiel ; les résultats du BAC officiels sont requis ; traduction anglaise par l'école ou agent certifiant. Les formulaires d'école passent par la plateforme.

## Étape 4 — Entretien indépendant (facultatif)

**Action** : réserver tôt [InitialView](https://initialview.com/), [Vericant](https://www.vericant.com/) ou l'entretien intégré au [Duolingo English Test](https://englishtest.duolingo.com/applicants) — un seul entretien au total. Soumettre la candidature avant de demander un entretien Bowdoin.

## Étape 5 — Essais

Essai principal + réponses Bowdoin (voir plateforme). Vérifier la politique IA de Bowdoin ([AI Policy](https://www.bowdoin.edu/admissions/apply/ai-policy/index.html)).

## Étape 6 — Soumission

Avant le 15 nov. (ED1) ou le 5 janv. (ED2/RD) — 23:59 de **votre** fuseau local (règle Common App). Conserver la confirmation ; suivre le [Bowdoin Application Portal](https://admissions.bowdoin.edu/apply/status/).

## Étape 7 — Après admission — aide financière

Dès l'offre : soumettre le **CSS Profile** + tout justificatif demandé **sous 7 jours** ; si le paiement du CSS Profile est impossible, écrire à [sao@bowdoin.edu](mailto:sao@bowdoin.edu). L'offre d'aide arrive via le portail admissions.
