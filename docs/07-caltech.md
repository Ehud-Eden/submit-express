## 1.3 Prérequis académiques

Préparation exigée (officiel) : **4 ans de mathématiques dont calcul (calculus 1-2)** ; 1 an de physique ; 1 an de chimie ; biologie (recommandée) ; 4 ans d'anglais ; 2 ans d'histoire/sciences sociales (3+ recommandés).
- IB : Higher Level Math requis ; A-Levels : A-Level Maths requis.
- Si un cours manque (indisponible), certificats/scores d'examen acceptés avec documentation du conseiller.
- **Point Burkina Faso** : le cursus du lycée burkinabè (séries C/D) couvre généralement maths/physique/chimie ; le calcul (notions de prépa) doit être documenté. [CONDITIONNEL — vérifier selon le profil]

## 1.7 Aide financière

- **Règle critique** : si vous pensez demander de l'aide financière **à un moment quelconque** du cursus, il faut la demander **dès la candidature d'admission**. Sans aide en 1re année → plus aucune aide possible ensuite (exceptions Canada/Mexique).
- Formulaire d'intention : [International Financial Aid Statement of Intent (PDF officiel)](https://www.admissions.caltech.edu/documents/6959/International_Financial_Aid_Statement_of_Intent.pdf).

## Étapes — synthèse opérationnelle

### Étape 1 — Prérequis et plan de tests

vérifier maths/calcul, physique, chimie, anglais, sciences sociales ; si lacune non résoluble, préparer la documentation avec le conseiller.

### Étape 2 — SAT/ACT

REQUIS. Créneaux limités au Burkina (centres possibles à Ouagadougou ou pays voisins) — s'inscrire plusieurs mois à l'avance. Dernières sessions utiles : [À CONFIRMER] sur [Standardized Tests](https://www.admissions.caltech.edu/apply/first-year-applicants/standardized-tests).

### Étape 3 — Anglais

REQUIS pour francophones — DET (130), IELTS (7/7) ou TOEFL (100 ancienne échelle / 5 nouvelle échelle) ; à passer **avant** la deadline d'application.

### Étape 4 — École

transcript original + traduction anglaise (par un professeur d'anglais ou un responsable d'école accepté) envoyé directement par l'école ; 2 recommandations (1 STEM, 1 humanités).

### Étape 5 — Essais

prompts officiels Caltech ; mentionner l'explication d'indisponibilité de test si applicable.

### Étape 6 — Aide financière

signer l'International Financial Aid Statement of Intent ; compléter le formulaire financier international indiqué sur [finaid.caltech.edu](https://www.finaid.caltech.edu/applying) ; préparer les justificatifs de revenus traduits.

### Étape 7 — Fee waiver

demander si les frais sont un obstacle (mécanisme détaillé dans l'application — [À CONFIRMER]).

### Étape 8 — Soumission

REA = non-contraignant mais exclusif (pas d'autres candidatures early privées) ; RD = 4 janv. 2027. Conserver la confirmation.

### Étape 9 — Suivi et après admission

portail candidat ; offre d'aide avec l'admission ; I-20 → visa F-1 ; reply deadline 1er mai.
