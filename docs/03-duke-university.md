## 1.10 Aide financière

- **Règle critique** : « Foreign citizens must apply for need-based financial aid in the original first-year application » — sans cela, aucune aide Duke possible pendant tout le cursus.
- Formulaires : **CSS Profile** (+ FAFSA citée par Duke — le FAFSA ne concerne que les citoyens/éligibles US ; pour un Burkinabè, seul le CSS Profile est applicable → [CONDITIONNEL — confirmer avec Duke s'il exige des documents supplémentaires à la place du FAFSA]).
- Deadlines : **ED — CSS Profile/FAFSA le 3 novembre** ; docs supplémentaires 15 nov. ; **RD — 1er février**.
- Adhésion au besoin : 100 % du besoin démontré ; bourses de 4 ans.

Sources : [Apply for Aid](https://financialaid.duke.edu/apply-aid/) · [Financial Support](https://admissions.duke.edu/financial-support/)

## Étapes — synthèse opérationnelle

### Étape 1 — Créer le compte Common App

[commonapp.org](http://www.commonapp.org) ; ajout de Duke en août ; vérifier les sections Profile/Family/Education.

### Étape 2 — Choisir ED ou RD

ED = engagement contraignant (si admis → inscription obligatoire, retrait des autres candidatures). RD = comparaison possible des offres. Sans financement confirmé, RD est plus prudent ; Duke ne publie toutefois pas d'offre d'aide avant l'admission dans les deux cas.

### Étape 3 — Coordination avec l'école

le lycée doit transmettre transcript traduit + originaux, School Report, recommandation du conseiller, 2 recommandations d'enseignants — directement via Common App. [Action directe — checklist Duke](https://admissions.duke.edu/checklist/).

### Étape 4 — Essais

essai principal Common App + réponses Duke. Authenticité exigée (statement Accuracy & Authenticity).

### Étape 5 — Tests facultatifs

OPTIONNEL — uniquement si le score renforce le dossier.

### Étape 6 — Anglais recommandé

TOEFL 100 / IELTS 7 / Duolingo 130 — recommandé pour un candidat burkinabè scolarisé en français.

### Étape 7 — Demande d'aide financière

cocher l'intention de demander l'aide dans la candidature Duke. Sans cette coche à ce stade, aucune aide Duke jamais.

### Étape 8 — CSS Profile

[cssprofile.collegeboard.org](https://cssprofile.collegeboard.org) — code Duke 2915 [À CONFIRMER] ; compléter la devise du pays d'origine ; prévoir les justificatifs de revenus 2025 traduits si demandés via le portail.

### Étape 9 — Frais ou waiver

waiver demandé dans Common App → endossement du conseiller requis.

### Étape 10 — Soumission

vérifier chaque section du Common App avant soumission ; soumettre avant 2 nov. (ED) ou 4 janv. (RD).

### Étape 11 — Suivi du portail

Duke envoie l'accès au portail candidat ; y suivre les documents manquants et la décision ; l'offre d'aide arrive avec l'admission ; après admission : Certificate of Financial Responsibility → I-20 → visa F-1.
