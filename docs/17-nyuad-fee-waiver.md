## 1.3 Règle critique

> « We cannot consider your fee waiver request after you apply for admission if you did not respond with "yes" on the Common Application. »

La demande **doit être faite avant/au moment de la soumission**, dans le formulaire Common App lui-même. Après soumission avec « no », plus aucune dispense possible. VÉRIFIÉ — SOURCE OFFICIELLE.

Autres points officiels :
- « Requesting a fee waiver will not disadvantage an applicant in any way. » (aucune pénalité)
- NYUAD « may request documentation at a later date, if necessary » (justificatifs possibles plus tard).

## 1.4 Procédure de demande

1. Dans Common App, pour NYUAD, la question posée à tous : « Do you feel that your financial circumstances might qualify you for an application fee waiver? » → répondre **« yes »**.
2. Dans la section fee waiver de Common App, sélectionner **le waiver qui correspond le mieux à votre situation** (plusieurs options proposées).
3. Le waiver est **approuvé automatiquement** — pas de validation préalable par le conseiller mentionnée pour NYUAD.
4. Payer 0 $ et soumettre.

## 1.5 Vérification de l'application

- Le reçu de paiement (ou de waiver) **ne vaut pas** soumission : vérifier sur le site Common App que la Common App **et** le supplement NYU requis sont bien soumis.
- Statut des frais à vérifier sur le portail candidat NYU après soumission.

## 1.6 Lien avec les frais CSS Profile (distinction importante)

Les frais de candidature (85 $) sont **différents** des frais du **CSS Profile** (formulaire financier pour l'aide institutionnelle NYUAD) :

| Frais | Montant | Dispense |
|---|---|---|
| Candidature NYUAD | 85 $ | Waiver automatique via « yes » dans Common App (ce fichier) |
| CSS Profile | 25 $ (+16 $/université) | « CSS Profile Fee Payment Code Request Form » NYU — demandable **uniquement après** avoir postulé à l'admission **et** activé le portail candidat NYU ; révisions à partir du 1er octobre ; **quantité limitée, premier arrivé premier servi** |

Source : [NYUAD — Apply for Financial Aid](https://nyuad.nyu.edu/en/apply/undergraduate/apply/scholarships-and-financial-aid/apply-for-financial-aid.html). Code école CSS NYU : **2785** (obligatoire, sinon NYU ne voit pas votre dossier d'aide). Deadlines CSS : ED I 10 nov. · ED II 10 janv. · RD 1er févr., 23:59 EST.

## Étapes — synthèse opérationnelle

### Étape 1 — Common App

ajouter NYU Abu Dhabi dans « My Colleges ».

### Étape 2 — Répondre « yes »

à la question « Do you feel that your financial circumstances might qualify you for an application fee waiver? ». Un candidat burkinabè sans ressources répond « yes » sans hésitation — aucune pénalité prévue.

### Étape 3 — Choisir le waiver

dans la section fee waiver, sélectionner l'option la plus pertinente.

### Étape 4 — Vérifier le statut

frais à 0 $ avant de soumettre.

### Étape 5 — Soumettre

Common App **et** NYU Supplement — les deux sont requis pour être éligible à l'admission. Conserver les confirmations.

### Étape 6 — CSS Profile

après soumission d'admission + activation du portail NYU, demander un code de paiement CSS via le [formulaire officiel NYU](http://connect.nyu.edu/manage/login?realm=&r=/register/intcsswaiver) — limité, agir dès le 1er octobre.
